这是 **WordPress 高级管理手册** 的代码仓库，由托管团队和文档团队协作完成。

### 示例域名

当使用示例域名时，请使用 _example.com_、_example.net_、_example.org_、_example.info_ 或 _example.biz_（以及你想要的任何子域名）。

国家/地区域名有其自己的示例名称，例如 _dominio.es_，这些可能需要核查。

请参阅 [RFC 2606](https://www.rfc-editor.org/rfc/rfc2606)、[.INFO 保留字符串](https://www.icann.org/en/registry-agreements/info/info-registry-agreement--list-of-reserved-tld-strings-26-5-2010-en)、[.BIZ 保留字符串](https://www.icann.org/en/registry-agreements/biz/biz-registry-agreement--list-of-reserved-tld-strings-19-6-2009-en)。

### 示例 IP / IP 网络 / IP 范围

当使用 IP 地址时，请使用：

- TEST-NET-1: 192.0.2.0/24 (192.0.2.0–192.0.2.255)
- TEST-NET-2: 198.51.100.0/24 (198.51.100.0–198.51.100.255)
- TEST-NET-3: 203.0.113.0/24 (203.0.113.0–203.0.113.255)

请参阅 [RFC 1166](https://datatracker.ietf.org/doc/html/rfc1166)。
