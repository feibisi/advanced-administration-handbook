## 在 AWS 上安装 WordPress {#installing-wordpress-at-aws}

* [由 Bitnami 和 Automattic 认证的 WordPress](https://aws.amazon.com/marketplace/pp/prodview-bzstv3wbn5wkq)。WordPress 是全球最受欢迎的内容管理平台。它包含新的 Gutenberg 编辑器以及超过 45,000 个主题和插件。此镜像由 Bitnami 认证为安全、最新且采用行业最佳实践打包，并得到 WordPress 背后的专家 Automattic 的批准。
* [由 Bitnami 和 Automattic 认证的带 NGINX 和 SSL 的 WordPress](https://aws.amazon.com/marketplace/pp/prodview-s6cuqgfczpuwm)。带 NGINX 和 SSL 的 WordPress 通过 SSL 自动配置和高性能 NGINX Web 服务器增强了 WordPress。此镜像由 Bitnami 认证为安全、最新且采用行业最佳实践打包，并得到 WordPress 背后的专家 Automattic 的批准。
* [带 LiteSpeed 缓存的 WordPress（由 OpenLiteSpeed 驱动）](https://aws.amazon.com/marketplace/pp/prodview-w7ee7rs5uhlem)。此 OLS + WordPress 镜像比常规 WordPress 镜像快 200 多倍。
* [由 Bitnami 和 Automattic 认证的 WordPress 多站点](https://aws.amazon.com/marketplace/pp/prodview-rcmdzzu2x3ntm)。WordPress 多站点使得从同一服务器和界面管理多个 WordPress 网站变得简单。此镜像由 Bitnami 认证为安全、最新且采用行业最佳实践打包，并得到 WordPress 背后的专家 Automattic 的批准。
* [在 AWS 中构建高度可扩展的 WordPress 站点架构](https://www.slideshare.net/harishganesan/scaling-wordpress-in-aws-amazon-ec2)。这是一份使用亚马逊关系数据存储 (RDS) 构建更昂贵、高度可扩展的 AWS 实施方案的指南。

## Installing WordPress at Microsoft Azure {#installing-wordpress-at-microsoft-azure}

* [Installing WordPress on Microsoft Azure](https://learn.microsoft.com/azure/app-service/quickstart-wordpress) is as simple as a few clicks. A hosting space and MySQL database will be created and configured, so you’re ready to start creating within a matter of seconds.
* Running into some issues and need to troubleshoot your WordPress site on Azure? Follow this handy [Troubleshooting guide for WordPress on Azure](https://learn.microsoft.com/troubleshoot/azure/app-service/web-apps-open-source-technologies-faqs).
* For other WordPress related content or specific WordPress related questions, you may perform a [search with WordPress related terms on Microsoft Learn](https://learn.microsoft.com/en-us/search/?terms=wordpress).
