# WordPress 调试

调试是网站开发的重要环节，也是确保用户获得流畅可靠体验的关键步骤。调试指的是在网站代码中查找并修复错误或问题的过程。

在《高级管理手册》的这一部分，我们将探讨 WordPress 网站调试的各个方面，包括常规 WordPress 调试、JavaScript 调试、WordPress 网络调试以及测试驱动。

## 常规 WordPress 调试

在[调试 WordPress 网站](https://developer.wordpress.org/advanced-administration/debug/debug-wordpress/)时，有多种方法和技术可供使用，包括在 WordPress 配置文件中启用调试、使用错误日志以及借助调试插件。这些技术有助于识别和解决各类错误，例如 PHP 错误和数据库错误。

## JavaScript 调试

[JavaScript 调试](https://developer.wordpress.org/advanced-administration/debug/debug-javascript/)对于确保网站前端交互和用户体验正常运行至关重要。本节将介绍如何使用浏览器开发者工具检查源代码并诊断 JavaScript 问题，同时提供更多实用技巧。

## WordPress 网络调试

维护 WordPress 站点网络时，[WordPress 网络调试](https://developer.wordpress.org/advanced-administration/debug/debug-network/)是必不可少的；它指的是对通过单一 WordPress 安装连接的多个站点进行调试的过程。这种设置通常被拥有多个网站的组织采用，这些网站共享一组通用的插件、主题和用户。

## 测试驱动

[测试驱动](https://developer.wordpress.org/advanced-administration/debug/test-driving/)指的是在网站上线前进行测试的过程。这个过程使开发人员能够在网站向公众开放之前识别并解决任何问题或错误。测试驱动通常在沙盒环境中进行。本节将介绍如何创建沙盒环境。
