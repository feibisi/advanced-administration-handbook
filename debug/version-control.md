# 版本控制

版本控制是一种追踪不同人员随时间对文件（如网站代码或其他应用程序）所做更改的方式。它允许人们追踪代码的修订历史，并通过命令行轻松回滚或应用更改。当网站出现问题时，这也是调试的好方法，因为您可以快速恢复到网站代码的先前状态，而无需从完整备份中恢复。

许多 WordPress 主机提供版本控制功能，但也有第三方服务和自托管选项可供选择。
