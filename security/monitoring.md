# 监控

网站监控系统和服务可以在您的网站运行异常时发出通知。它们通常能够自动修复轻微问题，或在问题恶化前协助您进行处理。

## 运行时间监控

运行时间监控传统上在服务器层面实施，或通过定期检查网站上一个或多个 URL 来确保其正常响应。结合内部与外部运行时间监控对用户最为理想，现有多种软件和服务可为您处理此项工作。

## 性能监控

虽然网站服务可能正常响应，但对用户而言，"正常运行"意味着更多内涵。性能监控类似于运行时间监控，但还会关注可能预示问题的特定指标。应定期监控并报告"页面加载时间"和"最慢平均事务处理"等指标，帮助您预防性能问题。监控问题查询或请求的慢日志也有助于保持用户网站稳定。MySQL、PHP-FPM 等工具均提供捕获此类信息以供监控的选项。

## 性能分析

最佳实践是使用性能分析工具（如 New Relic、AppDynamics 或 Tideways）来诊断网站和基础设施的性能瓶颈。这些工具能帮助您洞察导致性能低下的根本原因，例如执行缓慢的函数、外部 HTTP 请求、缓慢的数据库查询等。
