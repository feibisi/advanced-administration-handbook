# WordPress 用户与角色

WordPress 默认提供五种用户角色类型——若启用 WordPress 多站点功能则为六种：

1. __超级管理员__ 是多站点网络中的超级用户。他们可以创建和删除网络中的站点，并管理整个网络及其所有站点、用户、插件、主题和设置。超级管理员在网络内的任何站点中也拥有常规管理员权限。只有现有超级管理员才能授予或撤销其他用户的超级管理员权限。
2. __管理员__ 是单个 WordPress 站点中的超级用户。他们可以更新 WordPress 核心、插件和主题，可以安装、删除和编辑主题与插件。管理员能够编辑文件和用户，添加和删除用户。
3. __编辑__ 可以创建、编辑、发布和删除自己及其他用户撰写的页面和文章（包括私密和已发布内容）。他们可以管理分类、审核评论以及上传文件。
4. __作者__ 可以创建、编辑、发布和删除自己的文章，也可以上传文件。
5. __投稿者__ 可以创建、编辑和删除自己的文章，但无法发布。
6. __订阅者__ 没有内容管理权限，仅能阅读公开内容。但与未注册的访客不同，订阅者可以访问 WordPress 后台界面，并像其他用户一样编辑自己的基本账户设置。

首次安装 WordPress 多站点网络或独立站点时，系统会自动创建超级管理员和管理员账户。

超级管理员、管理员和编辑均被视为“可信”用户，这意味着他们拥有的权限可能被滥用以破坏或危害 WordPress 站点。

请注意：插件和主题可以修改默认的用户角色和权限。配置错误或存在漏洞的插件和主题可能允许任何用户行使任意权限，或将订阅者、投稿者、作者或编辑提升至管理员权限。
