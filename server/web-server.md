# Web 服务器

Web 服务器是一种软件，它接收用户的网络请求并提供相应的结果。许多不同的 Web 服务器运行在其他操作系统上。通常，只要您的 Web 服务器支持并执行 PHP 文件，它就应该能够运行 WordPress。

## Apache HTTPD

参见 [Apache HTTPD / .htaccess](https://developer.wordpress.org/advanced-administration/server/web-server/httpd/)

## nginx
