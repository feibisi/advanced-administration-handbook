# phpMyAdmin

## 什么是 phpMyAdmin？

phpMyAdmin 是一种管理员工具，它是一个 PHP 脚本，旨在让用户能够与他们的 MySQL 数据库进行交互。WordPress 将其所有信息存储在 MySQL 数据库中，并通过与数据库交互来生成 WordPress 站点内的信息。通过 phpMyAdmin，可以访问存储在 MySQL 数据库中的数据、表和字段的“原始”视图。

## 它有什么用处？

phpMyAdmin 程序便于对表执行维护操作、备份信息，以及在 WordPress 无法正常工作时直接编辑内容。有时，在[支持论坛](https://wordpress.org/support/welcome/#asking-for-support)中，有人会发布一些有用的 SQL 查询，这些查询可以使用 phpMyAdmin 运行。尽管许多相同的任务可以在 MySQL 命令行中执行，但对许多人来说，这并不是一个可行的选择。

## 在哪里可以获取它？

通常，主机控制面板（如 cPanel 和 Plesk）已预装了 phpMyAdmin，因此您无需进行特殊操作即可使用它。它通常从数据库页面链接。请咨询您的主机是否提供此功能。

您可以从主要的 [phpMyAdmin 项目页面](https://www.phpmyadmin.net/)自行下载并安装 phpMyAdmin。
